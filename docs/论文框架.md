# 硕士论文框架（讨论稿）

## 论文题目（暂定）

基于大语言模型 AI Agent 的多无人机智能调度系统研究

---

## 故事线

### 一句话概括

传统多无人机调度系统依赖人工建模和专家经验，面对场景多变、约束复杂的实际需求时适应性差。本文提出一种基于大语言模型 AI Agent 的多无人机智能调度框架，通过 Agent 理解自然语言事件描述，自动完成任务分配、航迹规划和飞行风险评估，并支持动态环境下的在线重规划。

### 问题 → 方法 → 验证

```
问题：多无人机调度面临什么困难？
  ├─ 场景多变（侦察/配送/执法/巡检），每种场景的数学模型不同
  ├─ 约束复杂（航程/载荷/时间窗/风险/协同）
  ├─ 传统方法需要专家建模，换个场景就要重新设计
  └─ 动态环境变化需要在线调整

现有方法解决不了什么？
  ├─ 赵明的统一模型：只考虑航程代价，不考虑风险
  ├─ 传统 VRP 方法：场景单一，不支持统一框架
  └─ 现有系统：人工配置调度规则，不能理解自然语言指令

方法：我做了什么？
  ├─ 整体：AI Agent 驱动的调度框架
  ├─ 任务分配：改进的统一目标分配模型（扩展风险约束、返回策略、多目标权衡）
  ├─ 航迹规划：三维环境下的 A* 路径规划
  ├─ 飞行风险评估：多维度风险融合（法规/气象/障碍物/通信）
  └─ 在线重规划：两层重规划机制（航迹+分配）

验证：实验证明方法有效
  ├─ 不同场景下的分配效果对比
  ├─ 与赵明原始方法的对比（风险感知 vs 纯航程）
  ├─ 重规划的响应时间和方案质量
  └─ Agent 调度的端到端演示
```

---

## 创新点

### 创新点 1：基于 AI Agent 的多无人机智能调度框架

**对标：** 现有调度系统是"人配置规则 → 系统执行规则"

**创新：** Agent 理解自然语言事件描述，自动完成从事件理解到调度执行的全流程

**写法公式：** [前人做了什么] + [有什么不足] + [我做了什么改进] + [带来了什么效果]

```
传统调度系统依赖人工预配置的规则库（如"IF 火灾 THEN 派侦察机"），
场景变化时需要重新配置，缺乏灵活性。
本文提出基于 LLM 的 AI Agent 调度框架，Agent 根据事件语义自主决策调度策略
——自动提取事件类型、位置、紧急程度，并据此设定优化目标和权重，
实现从自然语言指令到调度方案的端到端智能生成。
```

**对应章节：** 第2章

### 创新点 2：融合风险评估的统一目标分配模型

**对标：** 赵明 2012/2016 的统一模型只考虑航程代价

**创新：** 在统一模型中引入多维度飞行风险评估，将法规、气象、障碍物、通信融入代价矩阵

```
赵明等人提出了统一目标分配模型，但仅考虑航程代价，
未纳入飞行风险评估。
本文在其模型基础上，引入法规、气象、障碍物、通信四维度风险评估，
构建了风险感知的统一代价矩阵，使分配结果同时优化效率与安全。
```

**对应章节：** 第3章

### 创新点 3：动态环境下的两层在线重规划机制

**对标：** 赵明的重规划只做航迹层面（Q学习），不涉及分配重规划

**创新：** 提出"航迹重规划优先、分配重规划兜底"的两层重规划机制

```
赵明提出基于 Q 学习的航迹重规划方法，但仅处理路径层面的调整，
当航迹规划无法解决（如目标不可达）时缺乏进一步的应对机制。
本文提出两层重规划机制：轻度变化时进行局部航迹重规划，
变化严重时触发增量式分配重规划，通过分层决策实现逐级升级。
```

**对应章节：** 第4章

## 创新性的写法原则

### 不要这样讲（空泛）

> "本文提出了一种基于AI Agent的无人机调度系统，具有创新性。"

### 要这样讲（有对标、有差异）

> "赵明等人 [X] 提出了统一目标分配模型，但仅考虑航程代价，未纳入飞行风险评估。本文在其模型基础上，引入法规、气象、障碍物、通信四维度风险评估，构建了风险感知的统一代价矩阵，使分配结果同时优化效率与安全。"

### 创新性写法公式

```
[前人做了什么] + [有什么不足] + [我做了什么改进] + [带来了什么效果]
```

### 硕士论文创新性的标准

创新点不需要"颠覆性"：

1. **有明确的问题** — 说清楚了别人没解决好的问题
2. **有合理的改进** — 方法在某个维度上比现有方法更好
3. **有实验验证** — 用实验证明了改进是有效的

不需要发明新算法，**在已有方法上做有针对性的改进，并实验验证**，就是合格的硕士论文创新。
