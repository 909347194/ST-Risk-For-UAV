> 版本：v1.0 | 日期：2026-08-30 | 状态：定稿

---

## 一、场景维度

| 维度 | 取值 | 说明 |
|------|------|------|
| **数量关系** | N ≥ M / N < M | UAV 多 vs 任务多 |
| **访问模式** | 单目标 / 多目标序列 | 一机一目标 vs 一机多目标需排序 |
| **返回策略** | 返回起点 / 就近机巢 / 不返回（单程） | 终点在哪 |
| **协同模式** | 独立执行 / 多机协同 | 多架 UAV 打同一目标？ |
| **时间约束** | 无时间窗 / 有时间窗 | 是否必须在指定时段到达 |
| **优先级** | 均匀 / 混合 | 任务有无轻重缓急 |
| **机型能力** | 同构 / 异构 | UAV 能力是否一致 |
| **任务依赖** | 无依赖 / 有前置约束 | 任务间有无先后顺序 |
| **动态性** | 静态一次性 / 动态插入 / 故障重分配 | 执行中是否变化 |

### 5. 动态场景

| # | 场景 | 触发事件 | 重规划层级 | 说明 |
|---|------|---------|-----------|------|
| 30 | 新任务插入 | 执行中新增紧急任务 | 分配重规划 | 增量式，只重新分配新任务 |
| 31 | UAV 故障 | 某架 UAV 失联 / 电量耗尽 | 分配重规划 | 故障 UAV 的未完成任务重分配给其他 UAV |
| 32 | UAV 能力下降 | 载荷损坏、电量不足 | 分配重规划 | 原分配不可行，需重新评估 |
| 33 | 新障碍出现 | 新建禁飞区 / 新雷达威胁 | 航迹重规划 | 分配不变，只调整航迹 |
| 34 | 气象变化 | 突发雷暴区域 | 航迹重规划 | 绕飞或等待 |
| 35 | 目标移动 | 嫌疑人/目标位置变化 | 航迹重规划 → 可能触发分配重规划 | 先尝试航迹调整，不行再重分配 |
| 36 | 目标取消 | 任务取消 / 目标消失 | 分配重规划 | 释放 UAV 资源 |
| 37 | 大面积环境变化 | 多条航迹不可行 | 完全重分配 | 回到第三层全量重算 |
| 38 | 通信中断 | 与 UAV 失去联系 | 本地自主决策 | UAV 端降级为自主模式 |

**重规划优先级：** 先尝试航迹重规划（第四层），解决不了才触发分配重规划（第三层）。

## 四、场景→算法映射

| 场景类别 | 核心算法 | 编码方式 | 目标函数要点 |
|---------|---------|---------|-------------|
| 一对一指派 | 匈牙利 | 一维数组 `[u1→t2, u2→t1]` | 单目标：综合代价最小 |
| 多目标 + 返回起点 | CW → DE → ALNS | 带序列的分组编码 | CVRP：路程 + 约束罚分 |
| 多目标 + 就近机巢 | CW(贪心选巢) → DE → ALNS | 分组编码 + 机巢选择 | OVRP：路程 + 机巢选择 + 约束罚分 |
| 多目标 + 不返回 | CW → DE → ALNS | 分组编码（无回程） | OVRP 变体：单程代价最小 |
| 多机协同 | DE → ALNS | 协同编码（多机→同一目标） | 协同代价 + 到达时间协调 |
| 任务依赖 | DE → ALNS | 编码 + 前置约束检查 | 代价 + 依赖违反罚分 |
| 冗余选择 | 匈牙利 + 启发式 | 选子集后退化为指派 | 最优子集选择 |
| 动态：航迹调整 | A\* / D\* Lite | 不涉及 | 航迹代价最小 |
| 动态：分配调整 | 增量 DE → ALNS / 完全重算 | 当前方案作为种子 | 未完成部分重新优化 |
